BerandaPerhitungan AHP

Perhitungan AHP

Atur kriteria dan perbandingan berpasangan. Seluruh tahapan dihitung otomatis oleh JavaScript dan tersimpan di browser.

1. Kelola Kriteria

Nama, arah preferensi (benefit/cost), dan keterangan kriteria dapat diubah. Setiap kriteria terhubung ke satu isian pada data infrastruktur.

2. Matriks Perbandingan Berpasangan

Baca: kriteria pada baris dibandingkan dengan kriteria pada kolom. Nilai lebih dari 1 berarti baris lebih penting; pecahan (mis. 1/3) berarti kolom lebih penting. Kolom di bawah diagonal terisi otomatis (kebalikannya). Perubahan langsung dihitung ulang dan disimpan.

Skala perbandingan Saaty
NilaiKeterangan
1Sama penting
3Sedikit lebih penting
5Lebih penting
7Sangat lebih penting
9Mutlak lebih penting
2, 4, 6, 8Nilai tengah di antara dua penilaian berdekatan
1/3, 1/5, ...Kebalikan: kriteria kolom lebih penting dari kriteria baris

Manajemen Data

Export DataUnduh seluruh data usulan, kriteria, bobot, dan identitas sebagai file JSON (cadangan).
Import DataPulihkan dari file JSON hasil export. Data saat ini akan diganti; ranking dihitung ulang.

Kosongkan data usulanMenghapus semua usulan agar siap diisi data penelitian. Kriteria dan bobot tetap.
Penyimpanan di browser

Data tersimpan di LocalStorage perangkat ini saja. Gunakan Export secara berkala sebagai cadangan, dan untuk memindahkan data antarperangkat.
